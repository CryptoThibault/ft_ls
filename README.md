# ft_ls

A C reimplementation of the `ls` command.

## Project layout

- `src/` contains the source files.
- `include/` contains the header files.
- `obj/` contains generated object files.
- `ft_ls` is the generated executable.

## Project conventions

- Each file implements one focused feature.
- Code must remain readable and easy to navigate.
- No comments are placed in source files.
- Explanations and architectural decisions are documented here.
- The Makefile provides the `all`, `clean`, `fclean`, and `re` rules.
